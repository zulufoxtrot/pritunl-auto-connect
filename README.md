# pritunl-auto-connect

`vpn` — lightweight Pritunl client wrapper for macOS.

Lightweight, stdlib-only Python wrapper around `pritunl-client` with automatic
TOTP generation and a launchd watchdog that keeps the VPN connected.

## What it does

- Connects your Pritunl profile using PIN + TOTP (RFC 6238, auto-generated, retried with a fresh code if rejected mid-flight)
- Watchdog daemon reconnects within ~15s of a drop or wake from sleep
- LaunchAgent starts at login (`RunAtLoad` + `KeepAlive`)

## Setup

1. Install the [Pritunl client](https://client.pritunl.com/) and import your
   profile (verify with `pritunl-client list`).

2. Create the config with your base32 TOTP secret (from Pritunl's OTP/2FA
   enrollment — the secret encoded in the QR code):

   ```sh
   mkdir -p ~/.config/vpn-connector
   cp config.example.json ~/.config/vpn-connector/config.json
   $EDITOR ~/.config/vpn-connector/config.json
   chmod 600 ~/.config/vpn-connector/config.json
   ```

   Only `totp_secret` is required. `profile_id` is auto-detected when exactly
   one profile is registered; `pin` is optional.

3. Install the LaunchAgent and CLI symlink:

   ```sh
   ./vpn install
   ```

   This writes `~/Library/LaunchAgents/com.local.vpn-daemon.plist`, starts the
   watchdog, and symlinks `~/.local/bin/vpn` to the script.

## Commands

| Command          | Effect                                                     |
|------------------|------------------------------------------------------------|
| `vpn connect`    | Connect using PIN + TOTP                                    |
| `vpn disconnect` | Disconnect                                                  |
| `vpn status`     | Show profile state (exit code 0 = connected)                |
| `vpn totp`       | Print current TOTP code (`--copy` → clipboard)              |
| `vpn ensure`     | One-shot: connect if not connected                          |
| `vpn daemon`     | Watchdog loop (used by the LaunchAgent)                     |
| `vpn install`    | Install LaunchAgent + symlink (re-run to update the plist)  |
| `vpn uninstall`  | Remove LaunchAgent + symlink                                |

## Files

- Config: `~/.config/vpn-connector/config.json` (0600) — see `config.example.json`; never commit the real one
- LaunchAgent: `~/Library/LaunchAgents/com.local.vpn-daemon.plist` — auto-generated by `vpn install` (committed copy is for reference)
- Log: `~/Library/Logs/vpn-connector.log`

## Uninstall

```sh
vpn uninstall
```
